## Три варианта для YouTube A/B-теста

Каждый заголовок образует одну смысловую пару со своей обложкой. При первой
приватной загрузке используется вариант A. Сам A/B-тест запускается только
после публикации через YouTube Studio.

| Вариант | Заголовок | Обложка | Угол |
|---|---|---|---|
| A | Моя сестра беременна от моего мужа — семья требует, чтобы я её простила | `thumbnails/a-sestra-beremenna.jpg` | главный конфликт |
| B | Семья выбрала мою сестру после её предательства \| Истории Reddit | `thumbnails/b-semya-vybrala-ee.jpg` | эмоциональное последствие |
| C | Четыре семьи, которые потребовали слишком многого \| Истории Reddit | `thumbnails/c-rodnye-pereshli-granitsu.jpg` | весь выпуск |

Обложки намеренно выдержаны в одном узнаваемом стиле: взрослая редакционная
комикс-иллюстрация, крупная эмоция, ограниченная палитра, крупный встроенный
русский текст. Сюжеты и композиции у трёх вариантов разные.

## После приватной загрузки

1. Открыть ролик на правильном канале `@ChonkerTalksRussia` и полностью
   проверить его в YouTube-плеере.
2. Проверить автоматически загруженную русскую дорожку
   `editorial-motion-captions.srt`. Вшитая нижняя строка остаётся частью
   изображения; отдельный SRT нужен для доступности, поиска и возможности
   отключаемых субтитров.
3. Проверить автоматические главы, заголовок, описание, источники, язык,
   категорию «Развлечения» и отметку «не для детей».
4. Добавить конечную заставку: подписка на канал; после появления второго
   выпуска — ещё и плейлист/следующее видео.
5. Закрепить комментарий:

   > Какая из четырёх историй задела сильнее всего — 1, 2, 3 или 4?
   > Где, по-вашему, заканчивается семейная поддержка и начинается нарушение
   > личных границ?

6. Только после отдельного разрешения сделать ролик публичным и в YouTube
   Studio запустить тест вариантов A/B/C. Оценивать победителя по доле
   просмотра, а не только по CTR.
